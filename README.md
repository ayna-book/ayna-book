# AYNA BOOK

AYNA BOOK একটি প্রাথমিক সামাজিক যোগাযোগ অ্যাপের প্রোটোটাইপ।

## ডিজাইন

- নেভি ব্লু ও সাদা রঙ
- মোবাইল-উপযোগী ডিজাইন
- পোস্ট তৈরি
- স্থানীয়ভাবে পোস্ট সংরক্ষণ
- পরীক্ষামূলক লাইক ও শেয়ার
- ছবি, ভিডিও ও অডিওর স্থানীয় প্রিভিউ
- ব্রাউজারের অনুমতি নিয়ে লোকেশন দেখানো
- প্রাথমিক PWA ও অফলাইন ক্যাশ

## গুরুত্বপূর্ণ

এটি একটি প্রাথমিক প্রোটোটাইপ।

প্রকৃত ব্যবহারকারী অ্যাকাউন্ট, নিরাপদ ব্যক্তিগত মেসেজ,
AI অনুবাদ, অনলাইন পোস্ট, সার্ভারভিত্তিক মিডিয়া আপলোড,
ভিডিও কল এবং লাইভ সম্প্রচারের জন্য ব্যাকএন্ড, ডেটাবেস
এবং প্রয়োজনীয় API বা পরিষেবা যুক্ত করতে হবে।

স্থানীয়ভাবে সংরক্ষিত পোস্ট অন্য ব্যবহারকারীদের কাছে
স্বয়ংক্রিয়ভাবে দেখা যায় না।

GPS লোকেশন নিজে থেকে স্যাটেলাইট ইন্টারনেট সরবরাহ করে না।
